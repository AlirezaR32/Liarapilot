LiaraPilot — راهنمای سریع استقرار روی پلتفرم لیارا (نسخهٔ تجاری)
=================================================================

این نسخه به «هیچ» متغیر محیطی نیاز ندارد: همهٔ توکن‌ها (GitHub/GitLab/لیارا/
هوش مصنوعی) بعد از دیپلوی، توسط هر کاربر داخل خود اپ در «تنظیمات» وارد و
رمزنگاری‌شده ذخیره می‌شوند.

پیش‌نیازها
----------
1) یک کلید API از کنسول لیارا بسازید: https://console.liara.ir/panel/api-keys
   (فقط برای اجرای دیپلوی از کامپیوتر خودتان — ایجنتِ مستقرشده به آن نیازی ندارد)
2) CLI لیارا را نصب و وارد شوید:
     npm i -g @liara/cli
     liara login --api-token <YOUR_API_TOKEN>

مراحل دیپلوی (۴ گام)
---------------------
گام ۱ — ورود به CLI (دستور بالا)

گام ۲ — ساخت دیسک پایدار «پیش از اولین دیپلوی» (الزامی؛ برای SQLite):
     liara disk create liarapilot-data -a <APP_NAME> --size 1

گام ۳ — دیپلوی (ساده‌ترین مسیر، اسکریپت گرافیکی راهنما):
     bash scripts/deploy.sh
   یا مستقیم:
     liara deploy -a <APP_NAME> -b iran -m
   (نیازی به «liara app create» نیست — در CLI 9.6 باگ دارد و
    «liara deploy» خودش اپ را می‌سازد.)
   (هیچ «liara env set» لازم نیست — DATABASE_URL را entrypoint
    تزریق می‌کند و کلید رمزنگاری در اولین بوت روی دیسک ساخته می‌شود.)

گام ۴ — بررسی سلامت و لاگ:
     curl https://<APP_NAME>.ir.liara.run/api/health
     bash scripts/logs.sh        # لاگ رنگی + حالت زنده

اتصال سرویس‌ها (داخل خود اپ — تنظیمات)
--------------------------------------
[ ] GitHub → «ورود با مرورگر» (کد یک‌بارمصرف در github.com/login/device)
    یا PAT با دسترسی repo.  مالک نصب می‌تواند Client ID اپ OAuth را یک‌بار
    در «تنظیمات ← ثبت OAuth App» ذخیره کند تا ورود مرورگری برای همه فعال شود
    (github.com/settings/developers → New OAuth App → Enable Device Flow).
[ ] GitLab → همان جریان مرورگری، یا PAT با دسترسی read_api.
[ ] لیارا → توکن API از console.liara.ir/panel/api-keys — با اعتبارسنجی
    زنده. همین، استقرار واقعی روی اپ‌های خودتان را فعال می‌کند.
[ ] هوش مصنوعی → هر کلید سازگار با OpenAI (OpenAI/Azure/OpenRouter/vLLM)
    + Base URL و Model (پیش‌فرض: gpt-4o-mini). «ذخیره و آزمایش» یک تماس
    واقعی با سرویس شما می‌زند.

نقش هوش مصنوعی: گفت‌وگو، تشخیص حادثه، گزارش استقرار — همیشه پشت دروازهٔ
تأیید انسانی؛ جمع‌آوری شواهد و اجرای عملیات کد قطعی است (بدون LLM).

چک‌لیست تست پس از دیپلوی
-------------------------
[ ] باز کردن آدرس اپ — فضای کاری خصوصیِ خودتان، فارسی RTL، بدون صفحه ورود
[ ] اتصال گیت‌هاب با مرورگر و دیدن «@username · متصل · از طریق oauth»
[ ] اتصال توکن لیارا و دیدن «لیارا وصل شد به‌عنوان {ایمیل}»
[ ] اتصال یک مخزن — تحلیل خودکار و برنامه استقرار فارسی
[ ] «مخازن من» ← فهرست مخزن‌های خودتان از گیت‌هاب/گیت‌لب دیده می‌شود
[ ] «اتصال و استقرار» روی یکی از مخزن‌ها ← تأیید ← لینک https://<app>.liara.run در صفحه پروژه
[ ] درخواست استقرار ← تأیید از «تأییدیه‌ها» ← پیشرفت زنده تا راستی‌آزمایی
[ ] پرسش در «گفت‌وگو» — پاسخ مستند به شواهد (بِج ChatGPT با کلید خودتان)
[ ] تغییر زبان به English و بازگشت — جابه‌جایی تمیز LTR/RTL

نکات
----
- اولین بوت کانتینر، اسکیمای دیتابیس را خودکار اعمال می‌کند (prisma db push).
- اگر بیلد روی پلن کوچک با OOM قطع شد، پلن را ارتقا دهید.
- دیسک باید قبل از اولین دیپلوی وجود داشته باشد (خطای Disk does not exist).
- متغیرها را هرگز از طریق کلید «envs» در liara.json مدیریت نکنید — دیپلوی با
  آن کلید همهٔ متغیرهای قبلی را پاک می‌کند (LiaraPilot هیچ متغیری لازم ندارد).

مستندات کامل پلتفرم: https://docs.liara.ir
